# 🏋️ FitLog — Workout & Fitness Tracker

FitLog is a modern workout tracking web application designed to help users discover workout plans, manage their daily workouts, save favorite plans, and track their workout progress in a simple and organized way.

## 🔗 Live Demo & Repository

* 🌐 **Live Demo:** https://fitlog-app-six.vercel.app/
* 💻 **GitHub Repository:** https://github.com/sabermahmud/fitlog-app

## 🚀 Technologies Used

* **Next.js** — React framework for building the application
* **React** — Component-based UI development
* **TypeScript** — Type-safe development
* **Tailwind CSS** — Responsive and modern styling
* **React Icons** — UI icons
* **REST API** — Fetching workout data
* **Context API** — Managing application state
* **React Toastify** — User-friendly toast notifications


## ✨ Features

* 🏋️ **Workout Plans** — Browse and explore different workout plans.
* 📋 **Workout Details** — View detailed information about each workout.
* 📅 **Today's Plan** — Manage workouts planned for the current day.
* ✅ **Mark as Done** — Mark completed workouts and track progress.
* 🔖 **Save for Later** — Save workouts to access them later.
* 🚀 **Start Workout** — Start a workout directly from the workout interface.
* 📊 **Progress Tracking** — Keep track of completed workout plans.
* 📱 **Responsive Design** — Optimized for mobile, tablet, and desktop devices.
* ⚡ **Modern UI** — Clean and responsive interface built with Tailwind CSS.

## 🎯 Project Goal

The goal of FitLog is to create a simple and user-friendly fitness platform where users can discover workouts, organize their plans, and keep track of their workout progress.

## 🛠️ Getting Started

Clone the repository:

git clone https://github.com/sabermahmud/fitlog-app
cd fitlog


Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open your browser and visit:
https://fitlog-app-six.vercel.app/
